# Referências do estágio 73

- `cartas-roupas.jpg`: as 16 cartas de roupa lado a lado. A folha é gravada
  pelo mesmo roteiro que desenha as cartas
  (`app/scripts/build-clothes-cards.mjs`), a partir dos mesmos desenhos. Serve
  para conferir de uma vez que a moldura, o fundo e o tamanho da peça são
  iguais nas 16.

As peças, os nomes e as estampas são criação do agente para esta
demonstração. Não representam produto, marca ou coleção de ninguém.
